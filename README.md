# Superstore Sales Analysis

## Project Overview
This project analyzes Superstore sales data using Excel to identify sales trends, profitable products, and regional performance.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts and data analysis

## Key Performance Indicators (KPIs)
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Total Orders:** 5,009
- **Average Order Value:** $458.62
- **Overall Profit Margin:** 12.47%

## Key Insights
- Technology generated the highest sales among the three product categories.
- The West region had the highest sales and profit.
- Phones generated the highest sales among product sub-categories.
- Copiers generated the highest profit.
- Tables recorded the largest loss, despite generating significant sales.
- Annual sales increased from $484,247 in 2018 to $733,215 in 2021.

## Recommendations
- Investigate why Tables are generating losses.
- Improve profitability in the Central region.
- Focus on products with strong sales and profit.
- Monitor sales trends to prepare for periods of high demand.

## Project Status
Excel analysis completed. SQL, Python, and Power BI analysis will be added in future stages.
